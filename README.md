# 🐱 Study Buddy — শিক্ষার্থীদের পড়াশোনার সঙ্গী

মাধ্যমিক পর্যায়ের শিক্ষার্থীদের জন্য একটি কিউট, বন্ধুসুলভ অ্যাপ যেখানে তারা প্রতিদিনের পড়াশোনার অগ্রগতি সংরক্ষণ, পর্যবেক্ষণ এবং বিশ্লেষণ করতে পারবে।

## 🏗️ Tech Stack
- **Frontend:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, shadcn/ui, Framer Motion, Recharts
- **Backend:** NestJS 11, TypeScript, Swagger, JWT, Passport
- **Database:** PostgreSQL 17, Prisma ORM 7, Redis
- **AI:** Google Gemini
- **Monorepo:** Turborepo + pnpm workspaces
